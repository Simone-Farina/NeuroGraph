# Plan 01-01: Ephemeral TTL Engine (Backend & UI)

<objective>
Implement the 14-day TTL cron job to wipe old chats and broadcast a proactive UI countdown.
</objective>

<requirements>
- 14-day TTL Ephemeral Discovery Engine
</requirements>

<must_haves>
- The DB cron or API successfully deletes chat messages older than 14 days to force extraction.
- The UI broadcasts the countdown in the Left Panel's Sidebar and turns red when `< 24h`.
</must_haves>

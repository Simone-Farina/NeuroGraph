# Plan 01-02: AI Bouncer Vector DB & UX Rejection

<objective>
Implement the AI Bouncer logic using `pgvector` to detect semantic collisions, and the System Card UX to present the "Append vs Force New" choice.
</objective>

<requirements>
- AI Bouncer (Duplicate Prevention)
</requirements>

<must_haves>
- The Neurogenesis tool evaluates similarity > 0.85 via pgvector and uses LLM to refuse creation of duplicate nodes, returning an "append suggestion" instead.
- The UI injects a custom React component stating "This insight closely matches your existing Neuron: [[Neuron Title]]."
- The UI presents two buttons: [ Append to Existing ] and [ Force New Neuron ].
- Blocked text is held in-memory in the React state of the Bouncer UI Card.
</must_haves>

## Implementation Steps

<step>
<action>
Create the AI Bouncer vector search utility.
File: `src/lib/ai/bouncer.ts`
Implement `checkNeuronCollision(embedding: number[])` which calls a Supabase RPC function (e.g., `match_neurons`) to find Neurons with `1 - (embedding <=> embedding) > 0.85`.
If a match is found, return the `{ id, title }` of the closest match.
</action>

src/lib/db/schema.ts
</read_first>
<acceptance_criteria>
- `checkNeuronCollision` exists and queries Supabase using `.rpc('match_neurons', ...)`
- It explicitly uses a threshold of 0.85.
</acceptance_criteria>
</step>

<step>
<action>
Update the Vercel AI SDK tools to use the Bouncer.
File: `src/lib/ai/providers.ts` (or wherever `executeNeurogenesis` tool is defined).
Before inserting the Neuron, calculate the embedding of the insight. 
Await `checkNeuronCollision()`.
If a collision occurs, DO NOT insert. Instead, return a JSON object `{ type: 'collision', matchId, matchTitle, insightText }`.
</action>

src/lib/ai/providers.ts
</read_first>
<acceptance_criteria>

</acceptance_criteria>
</step>

<step>
<action>
Create the `BouncerCard` UI Component.
File: `src/components/chat/bouncer-card.tsx`
Render: "This insight closely matches your existing Neuron: [[{matchTitle}]]."
State: `insightText` stored in component memory.
Buttons:
1. `<Button variant="default">Append to Existing</Button>` -> Calls `PATCH /api/neurons/{matchId}` with the `insightText`.
2. `<Button variant="ghost">Force New</Button>` -> Bypasses the bouncer and forces creation.
</action>

# Objective
Fix the critical stability and functionality bugs identified during the UX verification of the Advanced AI Editor, effectively closing the gaps in Phase 4.

## Context
The Advanced AI Editor integration suffers from three primary issues:
1. `RangeError: Maximum call stack size exceeded` in ProseMirror during typing, likely caused by recursive state updates or extension conflicts (specifically between `SlashCommandMenu` and Tiptap's update cycle).
2. The Slash command (`/`) fails to mount its popover menu.
3. The `/api/neurons/extract` endpoint throws a 500 error when the text debouncer fires.

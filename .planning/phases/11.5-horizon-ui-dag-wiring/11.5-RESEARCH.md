# Phase 11.5: Horizon UI & DAG Wiring - Research

## Findings

### Graph surface
- `src/components/graph/GraphPanel.tsx` currently fetches only `/api/neurons`, lays out only persisted nodes, and opens only neuron detail on click.
- React Flow currently registers a single node type, `neuron`, and a single edge renderer, `synapseEdge`.

### Shell and left-panel state
- `src/stores/graphStore.ts` already owns:
  - `leftPanelMode`
  - `shellPreset`
  - `activeNeuronId`
- The store does not yet support:
  - ghost-path drafts
  - target text
  - active ghost node
  - briefing mode

### Existing handoff pattern
- `CrystallizeBootstrap` already proves the app can move from a lightweight intent into a seeded chat session.
- The ghost-node CTA should reuse that intent-driven pattern rather than inventing a second ad hoc chat bootstrap.

## Research Conclusion

Phase 11.5 should split into three slices:
1. Authenticated Architect route plus ephemeral draft state
2. GraphPanel trigger plus `ghostNeuron` rendering
3. Briefing-mode bridge from ghost node into a seeded chat session

That keeps the phase narrow: preview the path, inspect one node, start learning.

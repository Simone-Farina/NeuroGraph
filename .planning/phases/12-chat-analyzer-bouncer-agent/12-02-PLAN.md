**Update `prompt-eval/bouncer/promptfooconfig.yaml` — add extraction assertions (per D-05).**

Replace the full file with:

```yaml
description: NeuroGraph Golden Bouncer suite
prompts:
  - file://prompt.txt
providers:
  - exec:node ../shared/neurograph-bouncer-provider.mjs
defaultTest:
  assert:
    - type: is-json
      value: file://../shared/bouncer-response.schema.json
    - type: javascript
      value: |
        const result = JSON.parse(output);
        return result.decision === context.vars.expected_decision;
    - type: javascript
      value: |
        const result = JSON.parse(output);
        if (context.vars.expected_match_title) {
          return result.match_title === context.vars.expected_match_title;
        }
        return result.match_title === null;
    - type: javascript
      value: |
        const result = JSON.parse(output);
        if (result.decision !== 'allow_new') return true;
        if (typeof result.extracted_definition !== 'string' || result.extracted_definition.length < 10) return false;
        if (typeof result.extracted_core_insight !== 'string' || result.extracted_core_insight.length < 10) return false;
        return true;
    - type: javascript
      value: |
        const result = JSON.parse(output);
        if (result.decision !== 'allow_new') return true;
        const defFrag = (context.vars.expected_definition_fragment || '').toLowerCase();
        const insFrag = (context.vars.expected_insight_fragment || '').toLowerCase();
        if (!defFrag && !insFrag) return true;
        const defOk = defFrag ? result.extracted_definition.toLowerCase().includes(defFrag) : true;
        const insOk = insFrag ? result.extracted_core_insight.toLowerCase().includes(insFrag) : true;
        return defOk && insOk;
tests: cases.csv
```

**Assertion breakdown (5 total):**

1. **`is-json` (existing):** Validates all output against `bouncer-response.schema.json`. Catches structural violations. Hard pass/fail.

2. **`javascript` decision check (existing):** Validates `result.decision === context.vars.expected_decision`. Hard pass/fail for all cases.

3. **`javascript` match_title check (existing):** Validates match_title against expected. Hard pass/fail for duplicate cases, null check for allow_new cases.

4. **`javascript` extraction presence check (NEW):** For `allow_new` decisions only, validates that `extracted_definition` (string, >= 10 chars) and `extracted_core_insight` (string, >= 10 chars) are present. Skips entirely for `append_to_existing` cases. Hard pass/fail on presence.

5. **`javascript` extraction fragment check (NEW):** For `allow_new` decisions only, checks that extraction fields contain expected keyword fragments from the CSV `expected_definition_fragment` and `expected_insight_fragment` columns. Skips when both fragment columns are empty (i.e., the existing "Memory Palace" allow_new case and all append_to_existing cases). Scored/soft check based on keyword inclusion.

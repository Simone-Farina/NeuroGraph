**Create `prompt-eval/shared/neurograph-conversationalist-provider.mjs`** (per D-06):

Follow the established bouncer/architect provider pattern exactly. The provider reads `process.argv` for prompt/options/context, extracts system prompt, resolves model, runs heuristic or live mode.

Key differences from bouncer/architect providers (see Research Pitfall 4):
- Uses `messages` array (not single `prompt`) for multi-turn conversation
- Includes `suggest_neurogenesis` tool in live-mode `generateText` call
- Heuristic mode outputs `{ response, socratic_score, neurogenesis_triggered }` (not bouncer JSON)

Structure:
1. `extractChatPrompt()` — regex extract `CHAT_SYSTEM_PROMPT` from `src/lib/ai/prompts.ts` using pattern: `/export const CHAT_SYSTEM_PROMPT = \x60([\\s\\S]*?)\x60;/`
2. `resolveModel()` — check `PROMPTFOO_CONVERSATIONALIST_MODEL` env var, fallback to `AI_MODEL_EVALUATOR`, then `openai:gpt-4o-mini`; return null if `AI_PROVIDER=mock` or no API key
3. `hasKeyFor(provider)` — same as bouncer (check OPENAI_API_KEY, ANTHROPIC_API_KEY, GOOGLE_API_KEY)
4. `parseJson(raw, fallback)` — same as bouncer
5. `scoreSocraticTone(text)` — heuristic scoring per Research Pattern 3:
   - Count question marks: `Math.min(questionCount * 0.25, 0.5)` max 0.5
   - Coaching phrases: `['what do you think', 'how would you', 'can you explain', 'what happens when', 'why might', 'what if', 'consider', 'think about', 'reflect on', 'explore', 'what would']` — `Math.min(hits * 0.15, 0.3)` max 0.3
   - Direct answer penalties: `['the answer is', 'the solution is', 'to answer your question', 'here is how', "here's how", 'the way to do this is', 'you should do', 'the correct approach is']` — `-0.4` per hit
   - Clamp to [0, 1]
6. `detectsAnalyzeLevel(text)` — Bloom keyword heuristic per Research Pattern 3:
   - Signals: `/\bbecause\b.{5,}/i`, `/\bsince\b.{5,}/i`, `/\bcompared? to\b/i`, `/\bbetter than\b/i`, `/\bi think.{5,}because\b/i`, `/\bi realized\b/i`, `/\bthe (key|main|real) (difference|reason|point)\b/i`, `/\bthis (means|implies|shows)\b/i`
   - Question exemption: if text ends with `?` (after trimming), return false (per Research Pitfall 5)
   - Returns true if any signal matches
7. `buildMessages(vars)` — convert `vars.messages` array + `vars.final_user_message` into AI SDK messages format: `[...messages, { role: 'user', content: final_user_message }]`
8. `heuristicConversationalist(vars)` — offline fallback:
   - Builds a coaching-style response: "What aspects of [topic] are you most curious about? Consider how [concept] might connect to what you already understand."
   - Computes `socratic_score` from the heuristic response text
   - Computes `neurogenesis_triggered` from `detectsAnalyzeLevel(vars.final_user_message)`
   - Returns `{ response, socratic_score, neurogenesis_triggered }`
9. `main()`:
   - If no model: write `JSON.stringify(heuristicConversationalist(vars))` to stdout
   - If model available: call `generateText({ model, system: systemPrompt, messages: buildMessages(vars), tools: { suggest_neurogenesis: { description: '...', parameters: neurogenesisJsonSchema } }, temperature: 0, maxOutputTokens: 600 })`
   - Detect tool calls: `toolCalls.some(tc => tc.toolName === 'suggest_neurogenesis')`
   - Write `{ response: text, socratic_score: scoreSocraticTone(text), neurogenesis_triggered }` to stdout
   - On error: fall back to heuristic

4. **"Tone under pressure — frustrated user"** — 2-turn context where user says "I don't understand any of this, can you just explain it simply?" about neural networks. Expected: AI stays encouraging and Socratic, breaks down the question. `expected_neurogenesis: false`.

**Replace `prompt-eval/conversationalist/promptfooconfig.yaml`** (overwrite the Phase 10 echo placeholder):

```yaml
description: NeuroGraph Golden Conversationalist suite
prompts:
  - file://prompt.json
providers:
  - exec:node ../shared/neurograph-conversationalist-provider.mjs
defaultTest:
  assert:
    - type: javascript
      value: |
        // Scored Socratic tone assertion (D-07, D-08)
        // Threshold > 0.8 for coaching quality
        const result = JSON.parse(output);
        const score = result.socratic_score;
        return { pass: score >= 0.8, score, reason: `Socratic tone score: ${score.toFixed(2)}` };
    - type: javascript
      value: |
        // Hard pass/fail Neurogenesis assertion (D-09)
        // Checks neurogenesis_triggered matches expected_neurogenesis
        const result = JSON.parse(output);
        const expected = context.vars.expected_neurogenesis;
        if (expected === true) {
          return result.neurogenesis_triggered === true
            ? { pass: true, score: 1, reason: 'Neurogenesis correctly triggered' }
            : { pass: false, score: 0, reason: 'Neurogenesis should have triggered but did not' };
        }
        if (expected === false) {
          return result.neurogenesis_triggered === false
            ? { pass: true, score: 1, reason: 'Neurogenesis correctly withheld' }
            : { pass: false, score: 0, reason: 'Neurogenesis triggered when it should not have' };
        }
        // If expected_neurogenesis not set, skip this assertion
        return { pass: true, score: 1, reason: 'No neurogenesis expectation set' };
tests: cases.yaml
```

Key details:
- `prompts` references `file://prompt.json` (created in Plan 01)
- `providers` uses `exec:node` pattern matching bouncer/architect
- Two default assertions: scored Socratic tone (D-07) + hard pass/fail Neurogenesis (D-09)
- Tests loaded from `cases.yaml`

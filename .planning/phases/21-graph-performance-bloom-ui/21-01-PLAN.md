    - Change `export function NeuronNode(...)` to `export const NeuronNode = React.memo(function NeuronNode(...) { ... })`

    - Same pattern: `export const GhostNeuronNode = React.memo(function GhostNeuronNode(...) { ... })`

    In SynapseEdge.tsx:
    - Same pattern: `export const SynapseEdge = React.memo(function SynapseEdge(...) { ... })`

    IMPORTANT: Keep the function name inside React.memo (e.g., `React.memo(function NeuronNode(...))` not `React.memo((...) =>`). Named functions show correctly in React DevTools for debugging.

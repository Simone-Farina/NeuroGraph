    Export a constant array:
    ```typescript
    export const BLOOM_LEVELS = ['Remember', 'Understand', 'Apply', 'Analyze', 'Evaluate', 'Create'] as const;
    export type BloomLevel = typeof BLOOM_LEVELS[number];
    ```

    Export a function `classifyBloomLevel(userMessages: string[]): number` that:
    1. Takes an array of the user's message strings (most recent 3)
    2. Scans each message against keyword patterns for each Bloom level (use the research keyword anchors from FEATURES.md)
    3. Returns the highest detected level index (0=Remember through 5=Create)
    4. Default to 0 (Remember) if no messages or no signals detected
    5. Apply the BLOOM_QUESTION_EXEMPTION: if a message ends with `?` and would otherwise be Analyze+, cap it at Understand (index 1). This reuses the existing eval provider logic.
    6. Use the BLOOM_ANALYZE_SIGNALS patterns from the conversationalist provider as the Analyze-level patterns (do not duplicate — import or redefine them as TypeScript)

    Keyword pattern sets per level (from FEATURES.md research):
    - Remember (0): /\b(what is|define|list|name|who|when)\b/i
    - Understand (1): /\b(explain|describe|summarize|give an example|what does)\b/i
    - Apply (2): /\b(how would you|demonstrate|solve|calculate)\b/i
    - Analyze (3): BLOOM_ANALYZE_SIGNALS patterns (because, since, compared to, etc.)
    - Evaluate (4): /\b(judge|argue|which is better|critique|justify|is it valid)\b/i plus /\bi think.{5,}because\b/i
    - Create (5): /\b(design|propose|combine|what if we|novel approach)\b/i plus /\bi realized\b/i plus /\bi wonder\b/i

    The classifier scans ALL provided messages and returns the MAX level found across them. This means the meter only advances (never regresses) within a session — matching the "depth" metaphor.

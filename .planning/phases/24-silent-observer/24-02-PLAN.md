    **Part A: Create `src/app/api/bloom-evaluate/route.ts`**

    Create a POST endpoint that:
    1. Authenticates via `createServerSupabaseClient()` + `supabase.auth.getUser()` — return 401 if no user
    2. Validates body with Zod schema:
       ```typescript
       const bloomEvalSchema = z.object({
         messages: z.array(z.object({
           role: z.enum(['user', 'assistant']),
           content: z.string(),
         })).min(1),
         conversationId: z.string().uuid().optional(),
       });
       ```
    3. Extracts the last 3 user messages from the messages array (filter by role === 'user', take last 3)
    4. Reads the BLOOM_EVALUATOR_PROMPT — define it inline in this file as a const (DO NOT import from prompts.ts to keep the evaluator self-contained). Copy the prompt text from `prompt-eval/bloom-evaluator/prompt.txt`.
    5. Calls `generateText` (NOT generateObject — keep it simple with JSON-in-prompt parsing, same as the eval provider pattern) with:
       - `model: getModelForRole('evaluator')`
       - `system: BLOOM_EVALUATOR_PROMPT`
       - `prompt:` the last 3 user messages formatted as a numbered list
       - `experimental_telemetry: buildTelemetry('bloom-evaluator', { userId: user.id, conversationId })`
       - `maxRetries: 1`
       - `abortSignal: AbortSignal.timeout(10_000)` (10s — evaluator should be fast)
    6. Parses the JSON from the response text. Expected shape: `{ reasoning: string, bloom_level: string, confidence: number }`
    7. Returns `NextResponse.json({ bloom_level, confidence, reasoning })` on success
    8. On any error (parse failure, timeout, model error): returns `NextResponse.json({ bloom_level: null, confidence: 0, reasoning: 'Evaluation failed' }, { status: 200 })` — NEVER 500 (per CONTEXT.md anti-pattern: "better false positive than blocked user"). Use status 200 so the client doesn't need error handling.
    9. DO NOT use `after()` for flush — the response is JSON not streaming, so flush happens naturally before the function exits. If flush is needed, wrap the entire handler in try/finally with `langfuseProcessor.forceFlush()`.

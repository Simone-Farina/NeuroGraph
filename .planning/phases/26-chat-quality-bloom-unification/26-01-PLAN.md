Replace the broken scroll `useEffect` + `scrollTop = scrollHeight` implementation in ChatPanel with a sentinel element + `scrollIntoView` pattern that eliminates streaming jank.

Add a `scrollToBottom` callback (per D-01, D-05). Place it near the other useCallback definitions:
```typescript
const scrollToBottom = useCallback((instant = false) => {
  if (!isAtBottomRef.current) return;
  if (scrollDebounceRef.current) clearTimeout(scrollDebounceRef.current);
  if (instant) {
    sentinelRef.current?.scrollIntoView({ behavior: 'instant' });
    return;

    sentinelRef.current?.scrollIntoView({ behavior: 'smooth' });
  }, 16); // 16ms debounce — within D-05's 15-20ms window
}, []);
```

## Interaction Contract

### Scroll Behavior (CHAT-01)

These interactions are new in Phase 26 and are the primary UI change.

| State | Behavior |
|-------|----------|
| Streaming (tokens arriving) | Sentinel `<div>` at bottom of `MessageList` receives `scrollIntoView({ behavior: 'smooth' })` with 16ms debounce. Fires only when `isAtBottomRef.current === true`. |
| User scrolls up during streaming | `isAtBottomRef.current` set to `false` via `onScroll` handler. Auto-scroll pauses. Jump-to-latest button appears. |
| User scrolls back to bottom | `isAtBottomRef.current` set to `true`. Auto-scroll resumes on next chunk. Jump button fades. |
| Conversation load / switch | `isAtBottomRef.current` reset to `true`. Sentinel called with `scrollIntoView({ behavior: 'instant' })` — no debounce. |
| `scroll-smooth` CSS class | Removed from the scroll container div (`ChatPanel.tsx` line 391). `scrollIntoView` handles motion instead. |

Stick-to-bottom threshold: scroll is considered "at bottom" when `scrollHeight - scrollTop - clientHeight < 80px`.

## Sentinel Element Spec

The sentinel is a zero-height, zero-width DOM element appended as the last child of `MessageList`. It is the scroll target.

| Property | Value |
|----------|-------|
| Element | `<div ref={sentinelRef} aria-hidden="true" />` |
| Dimensions | 0px height, 0px width (no visual footprint) |
| Position | Last child inside the `space-y-4 px-8 py-8 md:px-12` container |
| ARIA | `aria-hidden="true"` — assistive technology skips it |
| Prop threading | `sentinelRef` passed from `ChatPanel` to `MessageList` via new `sentinelRef` prop on `MessageListProps` |

Source: CONTEXT.md D-01, RESEARCH.md Pattern 1 code example.

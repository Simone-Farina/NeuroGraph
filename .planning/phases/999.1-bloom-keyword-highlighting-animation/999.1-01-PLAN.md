    Replace:
    ```typescript
    .then((result: { bloom_level: string | null; confidence: number }) => {
      setBloomEval(result.bloom_level, result.confidence);
    })
    ```

    With:
    ```typescript
    .then((result: { bloom_level: string | null; confidence: number; key_phrases?: string[] }) => {
      const userMessages = messagesRef.current.filter((m) => m.role === 'user');
      const latestUserMessageId = userMessages.at(-1)?.id ?? null;
      setBloomEval(result.bloom_level, result.confidence, result.key_phrases ?? [], latestUserMessageId);
    })
    ```

    This captures the latest user message ID at the moment the Bloom eval result arrives. The message ID was present in the `messagesRef` when `triggerBloomEval` fired (the assistant has responded, so the user message is the second-to-last or earlier). Using `.at(-1)` on filtered user messages is robust because `triggerBloomEval` fires in `onFinish` after the assistant message lands.
